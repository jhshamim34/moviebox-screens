# MovieBox screen layouts

This repository contains the unzipped MovieBox frontend pack, organized by screen.

Each screen has its own folder. The folder includes the screen layout XML, included and referenced item or adapter layouts, related Java files, and a `screen_notes.txt` file listing detected values references. Shared files are copied into every screen folder that uses them. The original `values/` folder is also kept at the repository root.

The Java files are decompiled and are not compilable as-is. They are included for reference on purpose. The layout XML files are the real MovieBox UI and are the main visual reference in this pack.
